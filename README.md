# Sales Analytics Dashboard

## 📊 Project Overview

The Sales Analytics Dashboard is an interactive data analytics project developed using Microsoft Power BI. The project analyzes sales data to understand revenue performance, profit, sales trends, product performance, customer behavior, and regional sales distribution.

The dashboard transforms raw sales data into meaningful business insights using data cleaning, transformation, data modeling, DAX calculations, and interactive visualizations.

## 🎯 Project Objectives

* Analyze overall sales and profit performance
* Track revenue and profit trends over time
* Identify top-performing products and categories
* Analyze sales by region and location
* Understand customer purchasing patterns
* Compare sales performance across different segments
* Identify profitable and underperforming areas
* Create an interactive dashboard for business analysis

## 🔄 Project Workflow

### 1. Data Collection

Imported raw sales data from Excel/CSV files into Power BI.

### 2. Data Cleaning

Used Excel and Power Query to:

* Remove duplicate records
* Handle missing values
* Correct incorrect data types
* Standardize column values
* Remove unnecessary columns
* Check data consistency

### 3. Data Transformation

Used Power Query to:

* Create calculated columns
* Transform date fields
* Create useful categories
* Filter unnecessary records
* Prepare the dataset for analysis

### 4. Data Modeling

Created a structured data model in Power BI and organized the required tables and relationships for analysis.

### 5. DAX Analysis

Created DAX measures to calculate important business metrics such as:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Average Sales
* Average Order Value
* Profit Margin
* Monthly Sales
* Monthly Profit
* Sales Growth

### 6. Data Visualization

Created an interactive Power BI dashboard using:

* KPI Cards
* Line Charts
* Bar Charts
* Column Charts
* Donut/Pie Charts
* Tables
* Slicers
* Filters

## 📈 Dashboard Features

### Sales Overview

Displays key KPIs such as:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Profit Margin

### Sales Trend Analysis

Analyzes sales and profit performance over time to identify monthly and yearly trends.

### Product Analysis

Identifies:

* Best-selling products
* Most profitable products
* Low-performing products
* Sales by product category

### Regional Analysis

Analyzes sales and profit across different regions and locations.

### Customer Analysis

Provides insights into customer segments and purchasing behavior.

### Interactive Filters

Users can filter the dashboard based on:

* Date
* Region
* Category
* Product
* Customer Segment
* Other available business attributes

## 💡 Key Insights

The dashboard can be used to identify:

* Products generating the highest revenue
* Products generating the highest profit
* Regions with strong sales performance
* Categories contributing significantly to revenue
* Monthly sales trends
